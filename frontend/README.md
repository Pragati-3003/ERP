# Campus Diary ERP System

Campus Diary is a comprehensive, web-based ERP solution developed for **Banasthali Vidyapith** to automate and streamline academic and administrative operations. It facilitates role-based access and efficient management of key institutional processes for **students, teachers, and administrators**.

---

## 📌 Features

### 🎓 Students

- View attendance, results, and assignments
- Submit assignments with deadlines
- Access exam timetables and seat allotments
- Download admit cards and university notices
- Check course allocation and fee status

### 👩‍🏫 Teachers

- Mark and manage attendance
- Upload assignments and grade submissions
- Manage exam results and course allocations
- Access salary and duty placement details

### 🧑‍💼 Administrators

- Manage student and teacher profiles
- Define and monitor fee structures and salary records
- Upload notices, exam schedules, and results
- Handle course and timetable allocations

| Frontend        | React.js, Tailwind CSS                     |

---

## 🖥️ System Architecture

- **Modular Design:** Role-specific modules for students, teachers, and admins
- **Web-based Interface:** Accessible via any modern web browser
- **Responsive UI:** Optimized for desktop and mobile use
- **Communication Protocols:** HTTP over TCP/IP, secure JWT-based sessions

---

## 📄 Functional Requirements

- Role-based secure login and dashboard
- Student, teacher, and admin-specific functionalities
- Real-time data reflection for updates
- Assignment and fee management modules
- Notification system for deadlines and announcements

---

## 🧪 Testing Highlights

- **Unit Testing:** Components, modules, and UI behavior
- **Integration Testing:** Frontend–Backend–Database interaction
- **API Testing:** CRUD operations via REST APIs
- **Database Testing:** MongoDB consistency and indexing
- **UI/UX Testing:** Responsiveness and accessibility
- **Performance Testing:** Load testing during peak activities
- **Security Testing:** Role validation, XSS, CSRF, NoSQL injection protection

---

## 📋 Non-Functional Requirements

- **Availability:** 99.9% uptime guarantee
- **Security:** Strong role-based access and password encryption
- **Portability:** Cross-platform browser compatibility
- **Maintainability:** Modular codebase and documentation
- **Scalability:** Handles multiple concurrent users
